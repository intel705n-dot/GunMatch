# TCG Match Navi ロゴデザイン仕様書

## ブランド情報

| 項目 | 内容 |
|---|---|
| 正式名称 | TCG Match Navi |
| 日本語略称 | マチナビ |
| 英字略称 | TMN |
| サービス概要 | TCG（トレーディングカードゲーム）のガンスリンガー形式大会をリアルタイムで運営・参加できるWebアプリ |
| ターゲット | TCGプレイヤー（ポケカ、遊戯王、MTG等）、大会主催者 |
| プラットフォーム | スマホWebアプリ（PWA想定） |

## デザイン要件

### 必要なバリエーション
1. **メインロゴ** — 「MatchiNavi」または「TCG Match Navi」のロゴタイプ
2. **アイコン** — 「TMN」の3文字、またはシンボルマーク単体。favicon / アプリアイコン用（正方形、角丸）
3. **日本語ロゴ** — 「マチナビ」のロゴタイプ

### カラー
- ダークテーマ前提（アプリ背景: #0f172a〜#1e293b のスレート系）
- メインカラー: インディゴ系（#6366F1〜#4F46E5）を基調に、自由にアレンジしてOK
- アクセント: エメラルド（勝利）、レッド（敗北）をアプリ内で使用中
- ロゴ自体は白背景・ダーク背景どちらでも映えるものが望ましい

### テイスト・方向性
- **モダン・ミニマル** — ゲーミング寄りだが、派手すぎない
- **スピード感・回転感** — ガンスリンガー形式はプレイヤーが次々マッチングして回るのが特徴
- **カードゲーム要素** — トランプやカードのモチーフを入れてもいいが、特定のTCGに偏らないこと
- **ナビゲーション要素** — コンパス、矢印、パスなど「導く」イメージも合う

### 避けてほしいこと
- 特定のTCG（ポケモン、遊戯王等）を連想させるモチーフ
- 子供っぽすぎるデザイン（メインユーザーは10代後半〜30代）
- 細かすぎてスマホの小さいアイコンで潰れるデザイン

## 使用箇所

| 場所 | サイズ感 | 備考 |
|---|---|---|
| アプリヘッダー | 高さ32〜40px程度 | ダーク背景上に表示 |
| favicon | 32x32, 16x16 | ブラウザタブ用 |
| PWAアイコン | 192x192, 512x512 | ホーム画面追加用 |
| OGP画像 | 1200x630 | SNSシェア時のサムネイル |
| QRコード横 | 中サイズ | 大会参加URL共有時に表示 |

## 参考イメージ

以下のキーワードの雰囲気を参考に：
- 対戦ゲームのマッチメイキングUI
- eスポーツ系のクリーンなブランディング
- カードが回転する / シャッフルされるモーション

## 出力形式

- SVG推奨（Webアプリに直接組み込むため）
- PNG（透過背景）も併せて
- カラー版 + 白単色版（ダーク背景用）
