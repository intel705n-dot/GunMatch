| 項目 | 内容 |

## 4. ロゴデザイン

### 必要なバリエーション
1. **メインロゴ** — 「MatchiNavi」または「TCG Match Navi」のロゴタイプ + シンボルマーク
2. **アイコン** — 「TMN」の3文字、またはシンボルマーク単体。favicon / PWAアイコン用（正方形、角丸）
3. **日本語ロゴ** — 「マチナビ」のロゴタイプ
4. **カラーバリエーション** — フルカラー版 / 白単色版 / ダーク単色版

### テイスト
- モダン・ミニマル。ゲーミング寄りだが派手すぎない
- スピード感・回転感（ガンスリンガー形式は対戦がぐるぐる回る）
- カードゲーム要素を入れてもいいが、特定のTCGに偏らない
- ナビゲーション要素（コンパス、矢印、パスなど「導く」イメージ）も合う

### 避けること
- 特定のTCG（ポケモン、遊戯王等）を連想させるモチーフ
- 子供っぽすぎるデザイン
- スマホアイコンサイズで潰れる細かいディテール

### 使用箇所とサイズ
| 場所 | サイズ感 |
|---|---|
| アプリヘッダー | 高さ32〜40px |
| favicon | 32x32, 16x16 |
| PWAアイコン | 192x192, 512x512 |
| OGP画像内 | 1200x630の中央配置 |
| QRコード横 | 中サイズ |

## 5. UIコンポーネント

### ボタン
| 種類 | スタイル |
|---|---|
| プライマリ | オレンジ背景、白テキスト、角丸(12px)、ホバーでディープオレンジ |
| セカンダリ | 白背景、オレンジボーダー、オレンジテキスト |
| デストラクティブ | 赤背景、白テキスト（ドロップ、削除系） |
| ゴースト | 透明背景、グレーテキスト、ホバーでうっすら背景色 |
| 大アクション | プライマリの大きい版。マッチング開始ボタン等。影あり、押下でスケール縮小 |

### カード
- 白背景（#FFFFFF）、角丸(16px)、薄いシャドウ（box-shadow）
- ボーダーは基本なし、必要な場合はライトグレー
- 状態カード（���戦中、待機中等）はセマンティックカラーの左ボーダーまたは薄い背景色で区別

### バッジ・タグ
- 角丸フル(9999px)、小さめテキスト
- カードゲーム別バッジ: 各TCGの固有カラーで背景+テキスト
- ステータスバッジ: LIVE=赤パルス、待機中=ブルー、終了=グレー
- BO表示: BO3, BO5のインジケータ

### 入力フィールド
- ウォームグレー背景、角丸(12px)
- フォーカス時: オレンジのボーダーまたはリング
- ラベル: 上部に小さいグレーテキスト

### タブ・セグメント
- 背景にウォームグレーのピル型コンテナ
- アクティブ���ブ: オレンジ背景、白テキスト
- 非アクティブ: 透明、グレーテキスト

## 6. 画面デザイン

以下の各画面のモックアップまたはデザインイメージを作成してほしい。

### 6-1. ダッシュボード（HostList）
- ホスト / プレイヤー のタブ切り替え
- ホスト側: 大会一覧（アクティブ/待機中/終了/テスト）、「新しい大会を作成」ボタン
- プレイヤー側: QRスキャン参加ボタン、参加中の大会一覧
- アクティブ大会はLIVEバッジ+赤い通知表示で目立たせる
- 各大会カード��カードゲーム別バッジを表示

### 6-2. 大会作成（HostCreate）
- フォーム形式。上部にプリセット読み込みドロップダウン
- カードゲーム選択（必須、カテゴリ区切りドロップダウン + 選択後にカラーバッジ表示）
- BO1/BO3/BO5 のボタン選択
- 席移動ルールのラジオボタン（勝ち残り/負け残り/都度解散）
- 下部に「プリセット保存」ボタン → インライン保存フォーム
- 最下部に「大会を作成する」の大きなプライマリボタン

### 6-3. 大会管理（HostManage）
- ヘッダー: 大会名 + カードゲームバッジ + 席ルールバッジ + BOバッジ + 参加者数
- エントリー開始/締切ボタン、QRコード表示
- 設定変更エリア（バッファ、タイムアウト、最終マッチング時間）
- 進行中マッチ一覧（卓番号、プレイヤー名、タイマー、BOスコア、連勝バッジ）
- 参加者テーブル（番号、名前、W/L/連勝、ステータスバッジ、操作ボタン）
- ランキング表示切り替え

### 6-4. プレイヤーエントリー（PlayerEntry）
- 大会名 + カードゲームバッジ + 主催者名 + 説明文
- Googleログインボタン（大きめ）
- ハンドルネーム入力 + X ID入力（任意）
- エントリーボタン
- 再ログインタブ

### 6-5. プレイヤーメイン（PlayerMain）— 最重要画面
- **ヘッダー**: 大会名、カードゲームバッジ、ホーム/退室ボタン
- **戦績カード（ヒーローセクション）**: プレイヤー名、大きな勝敗数表示（Win - Lose）、勝率、対戦数、連勝表示
- **対戦中**: 卓番号+BO表示、対戦相手名、タイマー（大きく見やすく、テーブルに置いて使う）、BOスコア（BO3/BO5時）、勝者選択UI（確認ダイアログ付き）、修正ボタン
- **待機中（マッチング中）**: 検索アニメーション、キャンセルボタン
- **ポストマッチ（席キープ判定）**: 続ける/離席するの選択、カウントダウンバー（負け残り時）、卓キープ中の待機表示
- **対戦履歴**: 時系列リスト、WIN/LOSEバッジ
- **ドロップボタン**: 控えめだが見つけやすい位置

### 6-6. ランキング（Ranking）
- SNSスクリーンショット共有を意識し��デザイン
- ヘッダー: 大会名、日付、自分の順位（大きく）
- テーブル: 順位、プレイヤー名、W、L、勝率、最大連勝、OMW%
- 上位3名にメダルアイコン
- 自分の行をハイライト

## 7. 特殊UI要素

### タイマー表示
- 対戦中に卓上にスマホを置いてタイマーとして使う
- 大きく見やすいフォント、残り時間が少なくなると赤くなる
- BO3/BO5の場合���タイマーの上にスコア表示

### BOスコア表示
- BO3/BO5時: プレイヤー名 + 大きな数字で「1 - 0」のようなスコア
- 修正モード: タイマー停止表示 + 各ゲーム結果の修正UI

### LIVEバッジ
- 赤背景 + パルスアニメーション
- ダッシュボードの大会カードとマッチ履歴に使用

### マッチング検索���ニメーション
- パルスするサークル + 検索アイコン
- 「対戦相手を探しています...」のテキスト

### カードゲーム別バッジ
- 24タイトル + その他
- メジャー6タイトル: 各固有グラデーション
- 準メジャー: 共通ティール
- 新興・話題作: 共通フューシャ（明るめ）
- ニッチ: 共通スレート
- その他: グレー
